# 环境与数值检查

本轮独立环境为 `.venvs/lipm-balance`，Python 3.10、NumPy 1.26.4、SciPy 1.15.3、MuJoCo 2.3.7。完整版本在 requirements.lock.txt。

先导阶段发现既有 act-sim 的 NumPy 2.2.6 / MuJoCo 2.3.7 组合中，接触结构的 frame 读为零，导致世界坐标接触力换算为零；物体却确实受地面支撑。未用这些力读数形成正式结论。新建环境固定 NumPy 1.26.4 后接触坐标恢复，静态法向合力约220.725N，与22.5kg系统重力一致。没有修改 act-sim 或厂家工程环境。

LIPM参考轨迹采用向后求解DCM边界、向前积分稳定分量的形式，避免在长时间不稳定系统中直接向前积分参考造成漂移。实际模型通过与参考等价的误差坐标精确ZOH推进，保留模型高度偏差、推力和反馈误差，不重置物理状态。测试验证其与原状态方程逐步一致。

初轮按各自控制频率采样计算指标，后统一用1ms物理状态评价频率对照。初轮结果保存在 archive/native_rate_metrics，正式结果由当前 manifest.json 指向，不混入统计。改变物理步长的数值检查另列，不能当成不同机器上的重复试验。
