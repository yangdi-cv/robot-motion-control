Franka Panda 多关节轨迹跟踪与末端柔顺控制

2026年10月25—26日｜Isaac Sim 5.1.0｜Ubuntu 22.04 / RTX 4090

摘要

累计34组全长物理试验、599秒、599000条1ms力记录；另有1组由逆解保护提前终止。54组纯接口回放单独统计。全长试验包含失败对照，不代表全部控制方案合格。

本报告分为基础控制实验与执行接口扩展两部分。主实验采用普通关节PID，扩展保留质量矩阵补偿对照，并测试动作分块、延迟、目标跳变和断流恢复。全部物理实验在PC端Isaac Sim完成。

本次完成前三关节5秒五次轨迹和固定平面接触实验。采用相同普通PID关节内环比较位置控制与5N导纳控制，主条件为M=1、B=40。位置控制末两秒平均接触力为19.74N，导纳为5.01N；1ms原始接触力峰值分别为47.39N和95.32N。导纳改善了平均力误差，但并没有消除瞬时冲击。

实验使用Panda手部球形探针与水平面，关闭原装夹爪和其他连杆的碰撞，并统一关闭重力，以隔离法向接触控制。主实验的关节力矩由比例、积分和实测速度阻尼直接计算，不使用质量矩阵或科氏项补偿；补偿控制另列为扩展。全部结果来自实际运行的PhysX接触和关节状态，不包含实体机器人实验。

主实验之后，分别验证接触阶段切换与学习策略执行接口。接口实验使用已知五次参考生成动作块，不运行VLA网络；因此结果衡量延迟、限幅和超时机制，不能解释为VLA取放成功率。

稳定性改进后，在M=1/B=40和10ms普通PID内环保持不变的条件下，连续微分逆解、接触后冻结名义位置和指数反馈这一组合达到原有连续0.5秒标准。默认场景末2秒力RMSE约0.244N，最长带内跨度0.98秒；重复及平面高度±1mm也通过。后段仍有6%—18%的周期均力越界，尚未实现全程恒力。

2. 控制方法与代码

五次插值s(u)=10u³−15u⁴+6u⁵，u=t/5。普通PID输出直接作为关节力矩，D项使用实测角速度，避免目标跳变引起微分冲击。七轴增益按惯量差异配置，两种主条件完全相同。重力统一关闭，以隔离本轮轨迹与接触行为。增益单位为Kp：Nm/rad、Kd：Nm·s/rad、Ki：Nm/(rad·s)。

error = q_reference - q
integral = clip(integral + error * 0.01, -0.2, 0.2)
torque = kp * error - kd * dq + ki * integral
torque = clip(torque, -torque_limit, torque_limit)

导纳坐标的正方向取向下压入平面，PhysX向上的反力取正。用目标力减实测力驱动向下的附加位移；力偏大时附加位移减小。因此在世界Z坐标中需要减去导纳位移，不能直接照搬正负号。

acc = (5.0 - measured_force - B * velocity) / M
velocity = clip(velocity + acc * 0.01, -0.03, 0.03)
offset = clip(offset + velocity * 0.01, -limit, limit)
z_reference = z_nominal - offset

相关代码在 scripts/run.py。分析与图表在 scripts/analyze.py，运行条件在各 runs/<条件>/metadata.json。

慢速条件保持相同55mm最大名义接近位移，运行32秒，其余20秒。阻尼对照只改B，基准条件保持B=40；该表各项均使用补偿PID内环。位移限幅对照检验控制器是否因无法继续退让而产生稳态力偏差。重复运行用于检查本机确定性，不是不同初态的独立泛化样本。

B=20、40、80的首次峰值相同，因为接触前都已触及30mm/s导纳速度限幅；减慢名义接近速度虽降低冲击，仍未消除额外下压。接触后启用导纳直接处理了这个阶段切换问题。0.5秒目标力渐增只带来小幅进一步改善，不能据此声称优于其他方法或具有统计显著性。主条件重复运行的力序列一致，两个主条件前5秒的七轴实测轨迹也完全一致。

本轮触及的主要问题包括碰撞体遍历、时间步进和力信号采样。调试中发现带渲染的step与无渲染step会推进不同数量的物理步，已将旧运行移出正式统计；现改为每次只推进1ms物理步，再单独渲染，并逐步校验引擎时钟。20秒运行累计时钟差约1微秒，来自浮点步长表示。第一，USD实例化碰撞体需要先展开再检查，否则普通遍历会漏掉原夹爪碰撞，得到与设计不符的接触。第二，100Hz单点抽取会漏掉1kHz尖峰，所以同时保留原始峰值和周期平均力。第三，导纳输出存在速度、位移限幅，平均力接近目标并不能说明刚性接触完全稳定。

导纳主动让出位置精度来控制接触力。位置控制坚持向平面内部走，会持续增加反力；导纳会退让，但离散更新、刚性接触、逆解变化及关节内环共同影响波动。本轮尚未逐项分离这些因素，不能把所有波动归因于单一参数。

6. 扩展：学习策略动作执行接口

扩展目标是检查策略返回动作以后，执行端如何处理动作时标、突变和断流。参考LeRobot预测与执行解耦、动作队列的设计；本轮为独立的确定性接口测试，没有接入ACT、SmolVLA或WAM推理，也没有实现训练式RTC。

限幅将最大命令跳变从4.622°降至0.146°，峰值力矩从17.795Nm降至0.879Nm。平滑会改变原动作时序，因此不能只看动作更顺，还应核对跟踪误差及任务阶段。

超时保持与受限恢复使最大命令跳变从2.726°降至0.201°，但轨迹RMSE从0.532°增加到1.031°。这是有意暂停追赶带来的代价，不能写成所有指标都改善。超时触发1次；该保持机制尚未在重力、接触负载或真机上验证。

回归测试在5.01秒拦截了约66.4°的拟议跳变，未继续执行；该测试没有正常完成标记。它与此前无保护的失败记录分开保存。

7.3 连续微分逆运动学

使用Isaac关节雅可比和Lula正运动学，按相邻目标的位姿误差做阻尼最小二乘增量更新，避免每轮重新选择一整组逆解。正则系数0.01，每轴每轮增量不超过0.003rad，并按模型关节限位裁剪。导纳保持M=1/B=40，关节内环仍是普通PID。

pose_error = concatenate([target_position - FK_position(q_reference), rotation_error])
dq = J.T @ solve(J @ J.T + 0.01**2 * I, pose_error)
q_reference = clip(q_reference + clip(dq, -0.003, 0.003), lower, upper)

该雅可比来自当前实测姿态，正运动学在上次参考处计算，是局部近似；不保证大范围路径或奇异位形下仍适用。它沿用成熟控制链的连续增量设计，通过当前SDK公开接口实现，没有复制外部项目源码。

选择10ms控制、接触后冻结名义位置、连续微分逆解和α=0.2指数反馈这一组合。末2秒均力5.011N，力RMSE为0.244N，最长连续带内跨度0.98秒，达到原0.5秒标准。默认几何下末2秒94.0%样本在带内，仍存在越界。

8. 结论与后续工作

下一步检查当前尚未覆盖
接触控制重力、完整碰撞、接触刚度与摩擦变化，多初态重复测试
通信异常乱序、重复、无效数值、时钟偏移、延迟抖动与传输带宽
模型接入同一机器人和动作定义的真实策略；关节顺序、单位、绝对目标与增量的核对
实机当前限幅作用于命令；实际跟随、负载与碰撞边界需要独立验证

普通PID轨迹、接触力读取和M=1/B=40导纳对照已实际完成。M=1/B=40改善了平均接触力和接触阶段的位置跟踪误差，但原始尖峰仍明显，原基线未达到严格稳定条件；新组合在默认场景和±1mm平面扰动中通过了连续0.5秒标准，仍存在其他时段越界。当前结果支持“导纳能限制持续压入力”，不支持“已经实现无冲击精确恒力”。

下一步在接触控制中恢复重力与完整碰撞模型，并把真实策略动作接到已验证的时标、限幅和超时接口。当前仍是受控仿真原型，尚未达到生产部署条件。实体IMU高采样率、设备时间戳与Jetson测试属于另一组工作，不用本仿真结果替代。
