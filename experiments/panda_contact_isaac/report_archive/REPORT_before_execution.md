
# Franka Panda 多关节轨迹跟踪与末端柔顺控制

2026年10月25日｜Isaac Sim 5.1.0｜Ubuntu 22.04 / RTX 4090


## 摘要

本次完成前三关节5秒五次轨迹和固定平面接触实验。采用相同关节内环比较位置控制与5N导纳控制，主条件为M=1、B=40。位置控制末两秒平均接触力为19.23N，导纳为5.01N；1ms原始接触力峰值分别为43.21N和158.00N。导纳改善了平均力误差，但并没有消除瞬时冲击。

实验使用Panda手部球形探针与水平面，关闭原装夹爪和其他连杆的碰撞，并统一关闭重力，以隔离法向接触控制。内环是质量矩阵补偿的PID，不是未经补偿的纯关节PID。全部结果来自实际运行的PhysX接触和关节状态，不包含实体机器人实验。

进一步对照发现，接触前直接启用导纳会加快下压。改为检测到接触后启用，峰值降至27.24N；再加入0.5秒目标力渐增后为26.70N。所有条件仍未满足本报告严格的稳定接触标准。

## 2. 控制方法与代码

五次插值s(u)=10u³−15u⁴+6u⁵，u=t/5。PID输出为期望关节加速度，经质量矩阵和科氏/离心项补偿后转为力矩。重力已统一关闭，避免把未补偿的自重误差混进本轮接触对比。

```python
error = q_reference - q
integral = clip(integral + error * 0.01, -0.2, 0.2)
acceleration = 100 * error - 20 * dq + 5 * integral
torque = mass_matrix @ acceleration + coriolis
torque = clip(torque, -torque_limit, torque_limit)
```

导纳坐标的正方向取向下压入平面，PhysX向上的反力取正。用目标力减实测力驱动向下的附加位移；力偏大时附加位移减小。因此在世界Z坐标中需要减去导纳位移，不能直接照搬正负号。

```python
acc = (5.0 - measured_force - B * velocity) / M
velocity = clip(velocity + acc * 0.01, -0.03, 0.03)
offset = clip(offset + velocity * 0.01, -limit, limit)
z_reference = z_nominal - offset
```

相关代码在 scripts/run.py。分析与图表在 scripts/analyze.py，运行条件在各 runs/<条件>/metadata.json。

| 指标 | 位置PID | 导纳 M1/B40 |

| 1ms原始力峰值/N | 43.211 | 158.002 |
| 10ms平均力峰值/N | 20.349 | 16.140 |
| 末2s平均力/N | 19.233 | 5.006 |

| 严格稳定接触时间/s | 未达到 | 未达到 |

严格稳定接触时间定义为：从首次周期平均力超过0.5N起，到连续0.5秒内每个100Hz力样本均落在5±0.5N的时间。未达到表示本轮运行内未满足此条件，不填写0，也不以平均力接近5N代替。法向位置误差相对于各自实际发送的末端位置目标计算，导纳目标会随力反馈改变，因此不能把该误差单独作为优劣判据。

主条件的平均力虽接近5N，原始冲击峰值却高于位置控制。首次接触前的下降速度约为位置控制4.8mm/s、直接导纳35.1mm/s。原因是空中实测力为0，恒力导纳也在不断增加向下位移，叠加到名义接近速度上。


## 4. 参数对照与问题分析

| 条件 | 原始峰值/N | 末2s平均/N | 末2s力RMSE/N | 严格稳定时间/s |
|---|---|---|---|---|
| 阻尼B20 | 158.002 | 4.998 | 0.477 | 未达到 |
| 阻尼B80 | 158.002 | 5.004 | 0.479 | 未达到 |
| 接触后启用导纳 | 27.242 | 5.013 | 0.427 | 未达到 |
| 主条件 M1/B40 | 158.002 | 5.006 | 0.507 | 未达到 |
| 接触后0.5s力渐增 | 26.705 | 5.013 | 0.470 | 未达到 |
| 位移限幅±30mm | 158.002 | 5.702 | 0.851 | 未达到 |
| 主条件重复运行 | 158.002 | 5.006 | 0.507 | 未达到 |
| 接近速度2.5mm/s | 102.957 | 5.000 | 0.453 | 未达到 |

慢速条件保持相同55mm最大名义接近位移，运行32秒，其余20秒。阻尼对照只改B，主结论仍以导师指定B=40为准。位移限幅对照检验控制器是否因无法继续退让而产生稳态力偏差。重复运行用于检查本机确定性，不是不同初态的独立泛化样本。

B=20、40、80的首次峰值相同，因为接触前都已触及30mm/s导纳速度限幅；减慢名义接近速度虽降低冲击，仍未消除额外下压。接触后启用导纳直接处理了这个阶段切换问题。0.5秒目标力渐增只带来小幅进一步改善，不能据此声称优于其他方法或具有统计显著性。主条件重复运行的力序列一致，两个主条件前5秒的七轴实测轨迹也完全一致。

![直接导纳与接触后切换的对照：上图周期平均力，下图1ms原始力。](figures/transition.png)

本轮触及的主要问题包括碰撞体遍历、时间步进和力信号采样。调试中发现带渲染的step与无渲染step会推进不同数量的物理步，已将旧运行移出正式统计；现改为每次只推进1ms物理步，再单独渲染，并逐步校验引擎时钟。20秒运行累计时钟差约1微秒，来自浮点步长表示。第一，USD实例化碰撞体需要先展开再检查，否则普通遍历会漏掉原夹爪碰撞，得到与设计不符的接触。第二，100Hz单点抽取会漏掉1kHz尖峰，所以同时保留原始峰值和周期平均力。第三，导纳输出存在速度、位移限幅，平均力接近目标并不能说明刚性接触完全稳定。

导纳主动让出位置精度来控制接触力。位置控制坚持向平面内部走，会持续增加反力；导纳会退让，但离散更新、刚性接触、逆解变化及关节内环共同影响波动。本轮尚未逐项分离这些因素，不能把所有波动归因于单一参数。


## 5. 复现方式与代码目录

```python

  scripts/run.py           场景、PID、导纳和日志
```

## 6. 结论与后续工作

指定场景、轨迹、接触读取和控制对比已实际完成。M=1/B=40改善了平均接触力和接触阶段的位置跟踪误差，但原始尖峰仍明显，严格稳定条件是否满足以表格为准。当前结果支持“导纳能限制持续压入力”，不支持“已经实现无冲击精确恒力”。

下一步优先分离接触刚度、控制周期与滤波延迟的影响，再恢复重力和完整碰撞模型。实体IMU高采样率、设备时间戳与Jetson测试属于另一组工作，不用本仿真结果替代。
