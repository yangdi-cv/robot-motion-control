# 结果字段与视频阅读说明

旧包装的com_*字段实际取浮动基座qpos[:3]，不是全身质心。新验证分开记录base与whole_body_com。旧wall_seconds未覆盖完整视频编码与落盘，不能当完整可视化管线耗时；策略CPU执行也不代表EGL渲染不用GPU。

原记录不改写。新阶段的协议、状态、接触、视频与指标保存在studies/command_validation_v1。世界横移与机体系侧移不同，方向偏转时前向运动也投影为世界侧向位移。归零后仍踏步，不能把平均净速度降低称为站定。

原WBC是29电机准静态控制原型，官方RL是12电机预训练策略。两段原速视频的差异可以用于说明控制设置，不能作为严格算法消融。
