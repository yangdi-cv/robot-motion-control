# 上游来源与许可

本目录优先复现宇树官方开源动态行走基线，用于与自编准静态 WBC 原型对照。

| 项 | 内容 |
|---|---|
| 仓库 | https://github.com/unitreerobotics/unitree_rl_gym |
| 本地路径 | `upstream/`（shallow clone） |
| 提交 | `276801e46c5d433564f24658bac64f254b7d2d4b` |
| 许可 | BSD 3-Clause（见 `upstream/LICENSE`） |
| 本轮目标 | 官方预训 `deploy/pre_train/g1/motion.pt` 的 MuJoCo Sim2Sim + 指令矩阵评测 |
| 不做 | 不训练、不改策略网络、不连接真机、不替换自研 WBC |

## 两条路线如何定位

| 路线 | 定位 |
|---|---|
| 自编 WBC | 准静态控制原型：全身动力学约束、力矩控制、单脚承重、慢速交替迈步与失败分析。慢/不自然来自约 7 s/phase 的设计目标，不是“没研究明白”的同义词；真正欠缺的是动态参考、接触事件、状态估计等。 |
| 官方 RL | 动态行走策略的 Sim2Sim 复现（本目录）。12-DoF 腿部模型；与 29-DoF WBC 可比较观感，不可直接当同模型消融。 |

## 本地包装相对官方 `deploy_mujoco.py` 的差异

观测构造、PD、策略更新循环沿用官方实现。包装额外做了：

- 无显示器离屏渲染与 mp4
- **去掉**墙钟 realtime sleep（仿真按主机尽快推进）
- 固定仿真时长 / 跌倒启发式终止（高度 + 姿态倾角），而非 viewer 关闭
- 指标记录：浮动基座位姿/速度、横向漂移、姿态、速度误差

因此不能写成“只改渲染”。
